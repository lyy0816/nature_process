# THUCNews 新闻分类实验报告

## 1. 实验概述

本实验基于 THUCNews 中文新闻数据集，使用多层感知机（MLP）分类器对 10 类新闻进行文本分类。实验采用 PyTorch 深度学习框架，完成从数据加载、模型构建、训练调优到测试评估的完整流程。

## 4. 模型架构

### 4.1 MLP 分类器 (`model.py`)

```python
class MLPPClassifier(nn.Module):
    def __init__(self, input_dim=5000, num_classes=10):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(input_dim, 256),
            nn.ReLU(),
            nn.Dropout(0.5),
            nn.Linear(256, 128),
            nn.ReLU(),
            nn.Dropout(0.3),
            nn.Linear(128, num_classes)
        )
```

**函数解释：**

| 函数/组件 | 解释 |
|-----------|------|
| `super().__init__()` | 调用父类 `nn.Module` 的初始化方法，确保 PyTorch 模型的基础功能正常 |
| `nn.Sequential(...)` | 顺序容器，将各层按定义顺序组合；内部自动实现 `forward()` 方法，将输入依次通过每一层 |
| `nn.Linear(input_dim, 256)` | 全连接层，将输入维度 `input_dim` 映射到 256 维输出，实现特征的线性变换：$y = xW^T + b$ |
| `nn.ReLU()` | ReLU 激活函数，公式为 $\text{ReLU}(x) = \max(0, x)$，引入非线性，使网络能够学习复杂模式 |
| `nn.Dropout(0.5)` | Dropout 正则化，训练时随机丢弃 50% 的神经元连接，防止过拟合；评估时全部启用 |
| `nn.Linear(256, 128)` | 第二层全连接层，将 256 维特征压缩到 128 维，进一步提取高层语义特征 |
| `nn.Dropout(0.3)` | 第二层 Dropout，丢弃率降低到 30%，因为深层特征更需要保留 |
| `nn.Linear(128, num_classes)` | 输出层，将 128 维映射到类别数（10），输出每个类别的原始得分（logits） |
| `self.net(inputs)` | 调用 `nn.Sequential` 的前向传播，输入依次通过所有层，返回最终 logits |

网络结构：

```
输入层 (input_dim) → Linear → 256
                          ↓
                       ReLU
                          ↓
                     Dropout(0.5)
                          ↓
                      Linear → 128
                          ↓
                       ReLU
                          ↓
                     Dropout(0.3)
                          ↓
                输出层 (num_classes)
```

### 4.2 数据集类 (`dataset.py`)

```python
class THUCNewsDataset(Dataset):
    def __init__(self, X, y, max_len=None):
        self.X = X.astype(np.float32)
        self.y = y
        self.max_len = max_len or X.shape[1]

    def __len__(self):
        return len(self.X)

    def __getitem__(self, idx):
        features = self.X[idx]
        if len(features) > self.max_len:
            features = features[:self.max_len]
        else:
            features = np.pad(features, (0, self.max_len - len(features)),
                             mode='constant', constant_values=0)
        return torch.tensor(features, dtype=torch.float32), \
               torch.tensor(self.y[idx], dtype=torch.long)
```

**函数解释：**

| 方法 | 解释 |
|------|------|
| `__init__(self, X, y, max_len)` | 初始化数据集，`X` 为特征矩阵，`y` 为标签向量，`max_len` 控制特征维度上限；`.astype(np.float32)` 确保数据类型为 32 位浮点数以适配 PyTorch |
| `__len__(self)` | 返回数据集的样本总数，PyTorch 的 `DataLoader` 需要此方法来确定迭代次数 |
| `__getitem__(self, idx)` | 根据索引返回单个样本；通过截断（`[:max_len]`）或填充（`np.pad`）保证所有样本特征长度统一，返回 `torch.tensor` 供 PyTorch 使用 |
| `np.pad(features, (0, max_len - len(features)), mode='constant', constant_values=0)` | 在特征向量末尾填充 0，使其达到统一长度 `max_len`，填充值 0 表示"无意义"的占位 |
| `torch.tensor(..., dtype=torch.float32)` | 将 NumPy 数组转换为 PyTorch 浮点张量，用于模型输入 |
| `torch.tensor(..., dtype=torch.long)` | 将标签转换为 64 位整数张量，`CrossEntropyLoss` 要求标签为整数类型 |

**函数解释：**

| 参数/组件 | 解释 |

| `shuffle=False` | 测试/验证时保持数据顺序不变，确保结果可复现和评估的一致性 |

### 5.4 模型初始化

```python
device = torch.device('cuda' if torch.cuda.is_available() else 'cpu')
print(f"使用设备: {device}")

model = MLPPClassifier(
    input_dim=X_train.shape[1],
    num_classes=num_classes
).to(device)

criterion = nn.CrossEntropyLoss()   # 交叉熵损失
optimizer = optim.Adam(model.parameters(), lr=0.001)  # Adam 优化器
```

**函数解释：**

| 函数 | 解释 |
|------|------|
| `torch.device('cuda' if torch.cuda.is_available() else 'cpu')` | 检测是否有 NVIDIA GPU 可用：有则使用 CUDA 加速，否则回退到 CPU 计算 |
| `model.to(device)` | 将模型的所有参数和缓冲区移动到指定设备（GPU/CPU），确保模型和数据在同一设备上 |
| `nn.CrossEntropyLoss()` | 交叉熵损失函数，结合了 `LogSoftmax` 和 `NLLLoss`，用于多分类任务，自动处理 logits |
| `optim.Adam(model.parameters(), lr=0.001)` | Adam 自适应学习率优化器，`model.parameters()` 返回模型所有可学习参数，`lr=0.001` 为初始学习率 |
| `CrossEntropyLoss` 公式 | $L = -\sum_{i} y_i \log(\frac{e^{x_i}}{\sum_j e^{x_j}})$，衡量预测分布与真实分布的差异 |

### 5.5 训练循环

每个 epoch 的训练流程：

```python
for epoch in range(EPOCHS):
    model.train()                    # 切换为训练模式
    total_loss = 0.0

    for inputs, labels in tqdm(train_loader, desc=f"Epoch {epoch+1}/{EPOCHS}"):
        inputs = inputs.to(device, non_blocking=True)
        labels = labels.to(device, non_blocking=True)

        optimizer.zero_grad()         # 梯度清零
        outputs = model(inputs)       # 前向传播
        loss = criterion(outputs, labels)  # 计算损失
        loss.backward()              # 反向传播
        optimizer.step()             # 更新权重

        total_loss += loss.item()

    # ========== 验证阶段 ==========
    model.eval()
    correct = 0
    total = 0
    with torch.no_grad():
        for inputs, labels in test_loader:
            inputs = inputs.to(device, non_blocking=True)
            labels = labels.to(device, non_blocking=True)
            outputs = model(inputs)
            _, predicted = torch.max(outputs, 1)  # 取最大概率的类别
            total += labels.size(0)
            correct += (predicted == labels).sum().item()

    acc = 100 * correct / total
    avg_loss = total_loss / len(train_loader)
    train_losses.append(avg_loss)
    test_accs.append(acc)

    if acc > best_acc:
        best_acc = acc
        torch.save(model.state_dict(), os.path.join(RESULT_DIR, "best_model.pth"))
```

**核心函数详解：**

| 函数 | 解释 |
|------|------|
| `model.train()` | 将模型切换为训练模式，Dropout 层开始随机丢弃神经元，BatchNorm 层使用当前 batch 的均值/方差；仅在此模式下权重才会更新 |
| `tqdm(train_loader, ...)` | 进度条库，包装迭代器显示训练进度，`desc` 参数设置进度条前显示的文字描述 |
| `inputs.to(device, non_blocking=True)` | 将数据张量异步传输到 GPU（非阻塞），允许计算和数据传输并行进行，加速训练 |
| `optimizer.zero_grad()` | **关键步骤**：将所有参数的梯度清零。PyTorch 默认梯度会累积（`grad += ...`），若不清零会导致梯度叠加错误 |
| `model(inputs)` | 前向传播：将输入张量依次通过各层网络，最终输出 10 维 logits 向量（每个元素对应一个类别的未归一化分数） |
| `criterion(outputs, labels)` | 计算交叉熵损失：先将 logits 通过 Softmax 归一化为概率分布，再计算与真实标签的负对数似然 |
| `loss.backward()` | 反向传播：自动链式求导，计算损失函数对每个参数的梯度，存储在 `.grad` 属性中 |
| `optimizer.step()` | 参数更新：根据 `.grad` 中的梯度，使用 Adam 算法（包含动量+自适应学习率）更新每个参数的权重 |
| `loss.item()` | 从标量张量中提取 Python 浮点数，用于累加总损失；避免构建计算图以节省内存 |
| `model.eval()` | 切换为评估模式，Dropout 层的 `drop_prob=0`（保留全部神经元），BatchNorm 使用训练集的统计值 |
| `with torch.no_grad()` | 上下文管理器，禁用梯度计算和存储，显著减少内存占用和计算量，用于验证/测试阶段 |
| `torch.max(outputs, 1)` | 沿维度 1（类别维度）取最大值，返回 `(values, indices)` 元组，`indices` 即预测的类别索引 |
| `labels.size(0)` | 返回 batch 中标签的数量（64），`size(dim)` 获取该维度的尺寸 |
| `(predicted == labels).sum().item()` | 计算预测正确的样本数：`True/False` 张量求和得到正确数，再转为 Python 整数 |
| `torch.save(model.state_dict(), path)` | 以字典形式保存模型所有参数（权重矩阵和偏置），后缀通常为 `.pth` |
| `best_acc` 逻辑 | 记录验证准确率最高的模型，每轮若当前准确率更高则保存为 `best_model.pth` |

### 5.7 测试评估 (`test.py`)

```python
# 加载最佳模型
model.load_state_dict(torch.load(os.path.join(RESULT_DIR, "best_model.pth")))
model.eval()

# 批量预测
all_preds = []
all_labels = []

with torch.no_grad():
    for i in range(0, len(X_test), 64):
        batch_x = torch.tensor(X_test[i:i+64], dtype=torch.float32).to(device)
        outputs = model(batch_x)
        _, preds = torch.max(outputs, 1)
        all_preds.extend(preds.cpu().numpy())
        all_labels.extend(y_test_enc[i:i+64])

# 评估指标
acc = (all_preds == all_labels).mean() * 100
print(classification_report(all_labels, all_preds))
print(confusion_matrix(all_labels, all_preds))
```

**函数解释：**

| 函数 | 解释 |
|------|------|
| `torch.load(path)` | 从磁盘加载模型权重文件，返回包含所有参数的张量字典（Python 对象，非张量本身） |
| `model.load_state_dict(state_dict)` | 将加载的参数字典加载到模型中，设置 `model.parameters()` 的实际值 |
| `range(0, len(X_test), 64)` | 手动划分 batch：每 64 个样本为一批，从 0 到 `len(X_test)` 循环 |
| `torch.tensor(X_test[i:i+64], ...)` | 从 NumPy 数组切片创建 PyTorch 张量，`.to(device)` 同步传输到 GPU |
| `preds.cpu().numpy()` | 将 GPU 张量转回 CPU，再转为 NumPy 数组：`cpu()` 跨设备传输，`numpy()` 解除 PyTorch 封装 |
| `all_preds.extend(list)` | 将列表中的元素逐一追加到目标列表（区别于 `append` 将整个列表作为元素加入） |
| `(all_preds == all_labels).mean()` | 计算预测准确率：逐元素比较得到布尔数组，求均值即准确率（True=1，False=0） |
| `classification_report(...)` | Scikit-learn 函数，输出每个类别的精确率、召回率、F1 值和支持样本数 |
| `confusion_matrix(...)` | 混淆矩阵，行表示真实类别，列表示预测类别，对角线元素为正确分类数 |
